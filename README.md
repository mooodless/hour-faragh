📱 تعليمات العائلة (ضعها في README)
لأجهزة Android:
افتح الرابط من Chrome

اضغط القائمة (⋮) → "إضافة إلى الشاشة الرئيسية"

التطبيق يظهر كأيقونة

لأجهزة iPhone:
افتح الرابط من Safari (مهم — ليس Chrome)

اضغط زر المشاركة (□↑)

اختر "إضافة إلى الشاشة الرئيسية"

اضغط "إضافة"

ملاحظة :
التطبيق متاح لاي شخص يريد اخذ نسخه منه للتطوير لان البرنامج ينقصة التقييمات وجلبها ليس مجاني لذلك جرى التنويه
